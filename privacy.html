4. Data Sharing

We do NOT sell, trade, or rent your personal information to third parties.

5. Data Storage & Security

All data is stored securely on MongoDB Atlas cloud servers

All communication is encrypted using HTTPS/SSL

Passwords are hashed using bcrypt — never stored in plain text

Authentication uses JWT tokens with 7-day expiry

Access is role-based — clients can only see their own data

6. Data Retention

We retain your data for as long as your account is active. If you delete your account, all personal data is permanently deleted within 24 hours, except:

Payment records (kept for 3 years for legal/audit purposes)
